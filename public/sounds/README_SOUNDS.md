# Sound Files
Drop your Minecraft .ogg sound files here with these exact names.
The audio engine will automatically prefer these files over synthesized sounds.

Required filenames:
- click.ogg
- hover.ogg
- nav-select.ogg
- section-enter.ogg
- save-success.ogg
- tab-switch.ogg
- login-success.ogg
- page-load.ogg

Recommended sources:
- Extract from Minecraft .jar (assets/minecraft/sounds/) — for personal use only
- freesound.org — search "8-bit click", "retro button", "pixel game"
- mixkit.co/free-sound-effects/game/ — free game SFX

The site works perfectly without these files — synthesized sounds are the fallback.
